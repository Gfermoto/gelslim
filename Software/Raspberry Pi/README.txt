 RASPBERRY PI - Setup

   1) Возьмите Raspberry Pi 5 с microSD card (>=64gb)
   2) Установите Bookworm 64bit на microSD карту 
   3) Установите Dosker 
    - https://pimylifeup.com/raspberry-pi-docker/
   4) Установите ROS Melodic на Raspberry Pi 
    - https://raw.githubusercontent.com/Gfermoto/gelslim/main/Software/Raspberry%20Pi/run_ros.sh
   5) установите агента для подключения к Docker Socket (опционально)
    - https://docs.portainer.io/admin/environments/add/docker/socket
   6) Скопируйте файлы на Raspberry Pi и разархивируйте их в домашний каталог.
    - https://drive.google.com/file/d/1ZGIAz6NZ0dadbq10JgEx9H7Q8rlF-cqc/view?usp=drive_link
   7) Следуйте инструкциям в файле README графического интерфейса, чтобы настроить получение потокового видео с компьютером через Ethernet.
